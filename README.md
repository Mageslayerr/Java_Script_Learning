# Java_Script_Learning🤖💻

Welcome to my JavaScript learning repo.

This is where I’m learning JavaScript so that, one day, when AI gets too expensive, I can hopefully still build things without staring at my screen wondering why nothing works.

## 🎯 The Goal

Learn enough JavaScript to:

* Understand what the hell my code is doing
* Write JavaScript without relying entirely on AI
* Debug my own mistakes
* Build small projects from scratch
* Eventually build bigger projects without needing someone (or something) to hold my hand

## 📚 What I'm Learning

This repo will contain my notes, exercises, experiments, and increasingly complicated attempts at making computers do what I want.

Topics will include:

* JavaScript basics
* Variables
* Data types
* Functions
* Conditionals
* Loops
* Arrays
* Objects
* DOM manipulation
* Events
* APIs
* Asynchronous JavaScript
* Error handling
* Projects

## 🧠 Learning Philosophy

AI is incredibly useful, but I don't want to reach the point where I can only program if I have an AI sitting next to me.

The goal is to understand **why** something works, not just copy and paste something that works.

So when something breaks, I'm going to try to figure it out myself first.

...probably.
